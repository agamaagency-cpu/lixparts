# LIXPARTS — каталог запчастей Li Auto (Lixiang) L6 · L7 · L9

Премиальный адаптивный сайт-каталог оригинальных б/у кузовных и технических запчастей
Li Auto. Построен на **Next.js 14 (App Router) + React + Tailwind CSS** с
data-driven архитектурой: новые модели и категории добавляются через данные, без
переделки интерфейса.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшн-сборка (все страницы статические)
npm run start    # запуск продакшн-сборки
```

## Как наполнять реальными данными

Всё редактируется в **`lib/data.ts`**:

- **Добавить модель** — новый объект в `models[]`. Появятся: пункт меню, карточка на
  главной, страница `/catalog/<slug>`, товары, sitemap.
- **Добавить категорию** — объект в `categories[]` + slug в нужную группу
  `categoryGroups[]`.
- **Добавить товар** — сейчас товары генерируются из списка `seed[]` по всем моделям.
  Для реального наполнения замените генератор на явный массив `Product[]` (структура в
  `lib/types.ts`).
- **Контакты** (телефон, WhatsApp, Telegram, Instagram, адрес, график) — объект
  `contacts`. Сейчас стоят placeholder-значения — замените на реальные.

## Изображения

Пока используется компонент `components/PartImage.tsx` (аккуратный «студийный»
плейсхолдер). Для реальных фото замените его содержимое на `<img>` / `next/image`,
подставляя пути из поля товара (добавьте, например, `images: string[]` в тип `Product`).

## Формы

`components/LeadForm.tsx` сейчас собирает заявку и открывает WhatsApp с
предзаполненным сообщением. Для серверной обработки замените `handleSubmit` на
запрос к вашему API/CRM.

## Реализованные функции

Адаптив (desktop/tablet/mobile), sticky-хедер, хлебные крошки, фильтрация, поиск,
галерея с лайтбоксом, избранное, сравнение (до 3 позиций), запрос видео детали,
плавающая кнопка WhatsApp, конструктор ноуската, сравнительная таблица
«оригинал б/у / новая / дубликат», SEO (мета, ЧПУ-URL, sitemap, robots).
